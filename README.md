# Welcome to UX Hub ✨

This repo contains all UX Hub's projects:

```
uxhub/
├── apps/
│   ├── homepage/   # ubcuxhub.ca — public-facing club website
│   └── portal/     # Student Portal — membership sign-ups and event payments
└── packages/
    └── ui/         # Shared component library
```

## Getting Started

**Prerequisites:** Node.js, [pnpm](https://pnpm.io/installation) (`npm i -g pnpm`)

```bash
# Install dependencies
pnpm install

# Run a specific app
pnpm dev:homepage   # http://localhost:3000
pnpm dev:portal     # http://localhost:3001
```
